# 성적 CSV 검증 프로그램 (load_scores)

## ① 무엇을 하나요 (What)

성적 CSV 파일을 읽어 0~100점 사이의 유효한 점수만 골라 내고, 건너뛴 줄은 줄 번호와 이유를 함께 알려 줍니다.

## ② 왜 만들었나요 (Why)

실제 성적 파일에는 빈 점수, 0~100 밖의 점수, "결석" 같은 글자, 칸 수가 안 맞는 줄이 섞여 있습니다.
10주차에 AI에게 역할만 주고 받은 코드(v0~v3)는 scores.csv의 빈 점수 한 줄에서 ValueError로 멈춰,
나머지 정상 점수까지 하나도 읽지 못했습니다.
그래서 문제 있는 줄은 건너뛰되 조용히 넘기지 않고, 몇 번째 줄을 왜 건너뛰었는지 알려 주는 함수가 필요했습니다.

## ③ 어떻게 쓰나요 (How)

```bash
# 설치 (Python 3 필요)
git clone https://github.com/seor0811-sr/ai-programming-week11.git
cd ai-programming-week11
pip install pytest pytest-cov

# 실행
python load_scores.py scores.csv
```

## ④ 어떻게 테스트하나요

반드시 이 폴더 안에서 실행하세요. CSV 파일을 현재 폴더에서 찾기 때문입니다.

```bash
pytest
pytest --cov=load_scores --cov-report=term-missing   # 커버리지까지
```


커버리지는 80%입니다. 남은 77~86행은 `python load_scores.py`로 직접 실행할 때만 도는 부분이라 pytest로는 지나가지 않습니다.

## ⑤ 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `load_scores.py` | CSV를 읽어 `(kept, skipped)`를 돌려주는 함수. 직접 실행하면 결과를 화면에 출력 |
| `test_load_scores.py` | 정상 3 · 예외 3 · 경계값 6(-1, 0, 1, 99, 100, 101) 테스트 |
| `scores.csv` | 정상 줄과 문제 있는 줄이 섞인 예제 파일 (유효 5명) |
| `empty.csv` | 헤더만 있는 파일 (예외 테스트용) |
| `weird.csv` | 이름이 빈 줄 등 이상한 줄 모음 (예외 테스트용) |
